Pasang di Android

  1. Buka Noir atau Ivory di Chrome.
  2. Ketuk menu ⋮ → Tambahkan ke layar utama / Instal aplikasi.
  3. Buka dari ikon RIDA — tampil layar penuh seperti aplikasi.

Pasang di iPhone

  1. Buka Noir atau Ivory di Safari.
  2. Ketuk tombol Bagikan ⬆ → Tambah ke Layar Utama.
  3. Buka dari ikon RIDA di layar utama.

Data tersimpan di masing-masing perangkat (tidak ikut ke HP/komputer lain) dan Noir & Ivory punya buku terpisah. Unduh backup secara rutin dari menu Atur; untuk pindah perangkat, pulihkan file backup di perangkat baru.
